What it does

A small, data-agnostic, heavily customizable library — not a framework. You bring typed arrays and content callbacks; it renders and lets you fly.

🌌

Scale that stays flyable

A million nodes and their links at interactive framerates on an ordinary laptop GPU — not merely rendered, but navigated at 6-DOF.

🪐

N-level hierarchies

Group nodes on arbitrarily many levels. Each level picks its own shape, ordering, density, scatter and spin — galaxies of systems of worlds.

🔭

Zoom ladder

Distance-driven levels of detail: a node resolves from mote → label → card → full content as you fly toward it, with hysteresis so it never flickers.

⚡

GPU morphing

Switch arrangements, transpose 2D↔3D, and animate — all on the GPU. Per-frame CPU is O(pivots), never O(nodes).

🎛️

Customizable at three depths

Themes (pure data), shader hooks (inject TSL logic), and custom layers (bring your own objects, read our buffers).

🎯

Deterministic placement

Every position is a pure function of (data, spec). No RNG, no clock — byte-identical buffers forever, so screenshots reproduce and tests go golden.

Compose the pieces you need

The core never fetches and never knows what your data means. You map a format to typed arrays; starscape gives you a field, cameras, a pick grid, the zoom ladder and a schema-driven panel.

Full usage guide →

// map your data to typed arrays + callbacks
const graph = buildGraph({ n, positions, links, columns, facets, labels });

// two draw calls, TSL materials, WebGL2 fallback
const field = createField(graph, { heightCss: innerHeight, fov: 55 });
const scene = new Scene();
for (const o of field.objects) scene.add(o);

// fly it: a camera, a pick grid, the zoom ladder,
// and the schema-driven tuning panel
const cam = createFlycam(/* … */);
const levels = compileHierarchy(graph, spec);

Customizable at three depths

Reach for exactly as much power as the task needs — no forking required.

01

Themes — pure data

Palettes, ramps, node shapes, bloom and tonemap curves, the zoom-ladder thresholds. Change behavior by changing config, not code.

02

Shader hooks — inject TSL

Splice your own Three Shading Language nodes into the glyph, halo and link materials to recolor, displace or light the field however you like.

03

Custom layers — your own objects

Add arbitrary three.js objects that read starscape's live GPU buffers, so your overlays ride the same morph and spin as the field.

The Milky Way test

The north star: fly the full galaxy continuously — from the rim down to a single planet, close enough that Earth shows oceans and continents. The playground is where you feel it.
